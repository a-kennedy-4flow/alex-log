01The five rules

Remember these five if you remember nothing else.

  • Start with what already exists. Use the master and the slide design templates before you build anything from scratch.
  • Keep content inside the design area. Use the placeholders. Use the alignment tools. Keep spacing even.
  • Make slides easy to scan. Give each slide one clear headline. Show a visible hierarchy. Add only the detail the situation needs.
  • Design for the situation. A live presentation wants larger text and fewer details. A deck for distribution can explain more.
  • Use the 4flow system. That means the templates and the theme colours and the rounded corners and the approved images and the ready-made icons and the ribbon tool.

02Setup

Do this once. It takes five minutes.

Pin the master

  1. Save the .potx file to Documents → Custom Office Templates.
  2. Create that folder yourself if it is missing.
  3. Open Home or File → New.
  4. Click More themes.
  5. Find the 4flow template under Custom Office Templates.
  6. Click the pin icon.

Open the .potx once and restart PowerPoint if the template does not appear.

Set the default theme

  1. Open the .potx file.
  2. Go to Design.
  3. Open the full Themes gallery.
  4. Click Save Current Theme at the bottom.
  5. Save it as 4flow Master 7.0.
  6. Right-click the theme under Custom.
  7. Select Set as Default Theme.
  8. Restart PowerPoint.

What each one gives you

The pinned template gives quick access to the full master with every layout.

The default theme controls the colours and fonts of a new blank presentation.

The same theme file carries the 4flow palette into Excel.

03Start from a template

Slide design templates 2.0 holds over 100 on-brand layouts.

  • Numbers and comparisons and charts and processes and timelines and quotes and case studies are all covered.
  • Pick the layout closest to what you need. Swap the text.
  • Never rebuild from a blank slide unless it is unavoidable. Because a) rebuilding drifts the deck off brand and b) it costs you time.
  • The templates live on the hive.

Choosing white or warm

White and warm layouts are built to work together. Choose by the purpose of the slide.

Use white

Text-heavy slides.

Functional slides.

Send-out slides that must read without a speaker.

Use warm

Designed slides and brand moments.

Section dividers.

Storytelling that should feel distinctive.

04Covers and dividers and customer branding

  • Cover tag. Put the event name or the project name or the customer context in the tag. Write it as 4flow x Nike.
  • Cover image. Drag the image onto the key shape placeholder. It then fills the 4flow key shape.
  • Subtitle. The subtitle placeholder also takes a date.
  • Section dividers. Use them to structure a long deck instead of repeating the full agenda. Put the section topic in the big headline. Repeat the tag so the reader keeps orientation.
  • Customer logos. Add them in Slide Master view. Never place them by hand on each slide.
  • Logo position. Put the customer logo near the 4flow logo. Roughly 1 cm to its left. Adjust for the size of the logo.

05Moving an old deck across

Copy the slides. Never apply the master.

Do

Start a fresh deck from the new master.

Copy your existing slides into it.

The colours were matched closely to the old master so a transferred deck should still feel familiar.

Do not

Do not apply the new master to an existing file.

Because a) the old masters stay in the file and b) formatting breaks and c) it creates more cleanup rather than less.

No transfer is fully automatic

Positioning and sizing and colour always need manual cleanup afterwards.

06Fonts

Arial is the standard font. The master already uses it on every layout.

  • Use Arial. Because it renders reliably on almost every customer device. A missing font breaks the layout.
  • Use the predefined placeholders and styles.
  • Default text starts at 18 pt. It goes down to 11 pt.
  • Never go below 14 pt for a live presentation.
  • 11 pt works selectively in a deck for distribution.
  • Use the standard round bullets from the master.
  • A bullet always takes the colour of its text.

07Shapes

Rounded corners give the softer and more human look.

Rounded corners

  • Use rounded rectangles. Use rounded image corners.
  • A box works filled or as an outline only. Corners stay consistent either way.
  • PowerPoint scales the corner radius to the size of each shape. Similar boxes then look inconsistent.
  • Click Correct corners in the 4flow ribbon to fix it. It applies the standard radius across the whole presentation.
  • Insert shapes with 4f shapes. They arrive in the right sizes with the correct radius already set.

Connected shapes and masks and tags

  • The connected circles are a strong branding element. Never rebuild them by hand. Take the ready-made version from the slide design templates.
  • Use a connected-circle mask for a branded image crop. Place the mask over the image. Crop the image so nothing extends past the mask edge.
  • The masks are editable shapes. Recolour them directly in PowerPoint.
  • Use the pill-shaped tag as a short label or a descriptor or an orientation marker. It guides the reader without a heavy text block.
  • Insert a tag with 4f shapes to get the right sizing.

08Colours

Use the defined theme colours. Never make your own shade. Never take an automatic PowerPoint variant.

Smart Blue#00263CText and structure.
Warm Grey#EEE6E0Calm and clarity.
White#FFFFFFCalm and clarity.
Vibrant Orange#FF4D06Strong brand emphasis.
Bright Blue#007EFFCharts and selected highlights.
Bold Pink#FFA0F5A rare accent only.

Rule of thumb

  • Start with Smart Blue and Warm Grey and White.
  • Add Orange only where the emphasis is positive or is a brand moment.
  • Use Bright Blue and Pink selectively.
  • Fewer colours make the stronger slide.
The colour slots moved

The palette sits in a new order. An old slide copied into this master shifts each colour to the same slot in the new palette. Reassign those colours by hand.

09Images

Choose a photograph with people in it whenever you can.

  • An image supports the message. It never fills space.
  • People images build trust and atmosphere. They show openness and respect and authenticity and partnership.
  • Use an industry shot to connect with the world of the customer.
  • Use a detail shot to make a product or a process or a technology tangible.
  • Reach for a 4flow people image when the picture is there mainly for visual emphasis.
  • Use only 4flow images or client-approved visuals or properly licensed external assets. Never take a random image from the web.
  • Ask Marketing for a specific image or an industry visual or a clean detail shot.

Rounded image corners

  1. Insert the image and select it.
  2. Crop to Shape → Rounded Rectangle.
  3. Click Correct corners.

10Icons and illustrations

  • Use the custom 4flow icon set. Never use a generic icon.
  • Icons ship as SVG so you can scale and recolour them in PowerPoint.
  • Recolour an icon only in a defined 4flow brand colour.
  • Add an icon only where it explains or structures the content.
  • Illustrations come in isometric and flat styles. They use thin lines and technical shapes to explain a concept rather than draw a literal object.
  • Use an illustration only where there is enough space for it to work. It supports a bigger idea. It never fills a small gap.
  • Ask Marketing at least one week ahead for a specific illustration.
In development

An AI-based icon generator and a searchable icon database are both being built. An initial icon set is already available to download.

11Charts

  • Use a standard PowerPoint chart for clear data. It already carries the 4flow palette.
  • A standard chart needs no manual colour or shape adjustment.
  • Use a chart or infographic template when the message needs visual storytelling. Timelines and milestones and percentages and comparisons all have one.
  • Never redesign a chart from scratch where a 4flow template already fits.

12Tables

Keep a table light. A table structures information. It is not a heavy grid.

  • Use Bright Blue for internal lines only.
  • Leave off the outer border. The table then feels lighter and more open.
  • Set text in Bright Blue or Dark Blue.
  • Set backgrounds in Warm Grey or Dark Blue or White.
  • Use Bright Blue for a divider or a highlight.
  • Never build a custom table style from scratch. Copy a table from the slide design templates and adjust the text styling.

13The 4flow ribbon

The ribbon holds the shortcuts that keep a deck on standard.

Shapes and alignment

Create and style shapes.

Insert a ready-made tag or rounded rectangle.

Correct the corners of every rounded rectangle in the deck.

Align and rotate and mirror objects.

Dock a shape to another. Group. Match sizes.

Bring an object to the front or the back.

Helpful tools

Search and replace text.

Toggle the design area.

Crop an image or a shape.

Zoom.

Slice a shape equally.

Multiply shapes into a grid.

Change the spell check language.

Agenda tool

Edit the agenda in one place. Update every agenda slide at once.

  1. Go to the 4flow tab. Click Agenda → Add agenda.
  2. Add one agenda slide per main section.
  3. Press Tab for a sub-level.
  4. Edit the active agenda line on its own slide.
  5. Use Change Color to match the deck or to sharpen the hierarchy.
  6. Click Update Agenda to push the change everywhere.
  7. Use Next Agenda to jump to the next agenda slide.

The tool runs only in the 4flow master. Agenda numbers navigate during presentation mode.

Alignment and spacing

Align every object to the design area. Keep equal distances between related elements. Never place content by eye.

Correct corners works on rounded rectangles only.

14Standards

Abbreviations

  • Use only a common abbreviation. Explain any other one in a legend or a footnote.

Bullet points

  • A short phrase or a keyword takes no punctuation at the end.
  • Punctuate only where the whole bullet list forms one complete sentence. The last bullet then ends with a full stop.

Images and graphics

  • Use a visual only where it supports the message.
  • Use 4flow-created visuals or approved client material or external assets licensed for commercial use.
  • Translate all text inside a graphic to the language of the presentation.
  • A screenshot of 4flow software stays in English always.

File names

  • Use the format YYYYMMDD_Client_Project_Type_Version.
  • Project takes either the project number or a short project name.
  • Examples are 20101231_MAN_1234567_SteerCo_v1 and 20101231_MAN_Optimization_SteerCo_v1.

15Checklist

Run this before you send a deck.

  • Started from the 4flow master 7.0 or from the slide design templates.
  • All content sits inside the design area.
  • Arial throughout with the predefined text placeholders.
  • Nothing below 14 pt in a live presentation.
  • Only defined 4flow theme colours. No automatic PowerPoint shade.
  • Rounded rectangles used. Correct corners clicked.
  • A people image wherever the visual is there for atmosphere or emphasis.
  • Image and chart and table and infographic templates used rather than rebuilt.
  • Tables light. Bright Blue on internal lines only. No outer border.
  • Old slides copied into a fresh master file. The master was never applied to the old file.
  • Agenda slides built with the agenda tool.
  • Alignment and spacing and colours and images and corners checked for consistency.
