Chosen 2026-09-22. Option B. Sliders that hold the hundred. What one row takes the others give up in the proportion they already held. The total is a hundred at every moment so the error message never appears and 100 / n is only a starting point. Hold pins a row so a share the user has settled is not moved by the next drag. It costs predictability. A drag on one row rewrites three figures the user did not touch, and that is the thing people distrust in a control like this. Hold is the answer to it and it is one more thing to learn. It costs column width. It also costs the last row: with three rows pinned a drag has nowhere to put the remainder and the handle stops dead. Built in SimpleView.vue with the balancing in balanceShares in core. The share cell went to two lines there rather than the one this page uses, because the running app gives the table 732 px and the cost centre column takes 321 px of it, which put the figure off the visible table. Two lines also give the track 148 px where one line left it 95 px.
