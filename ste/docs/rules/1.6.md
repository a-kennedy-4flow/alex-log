# Rule 1.6 — Words that are not approved

**Statement** (Issue 9, page 1-1-9)
> Use a word that is not approved in the dictionary, only when it is a technical
> noun or part of a technical noun.

- **Applies to:** every word that the dictionary lists as not approved.
- **Needs:** dictionary, glossary.
- **Decidable:** yes, against a glossary.
- **Code:** not implemented on its own; rule 1.1 gives the same verdict for the
  single-word case.

## Discrete form

```
check(text, dictionary D, glossary G) -> [finding]

for each word w of text that D lists as NOT approved:
    if G lists w as a technical noun:                         continue
    if w is part of a multi-word technical noun of G that the
       text uses here (longest match around w):               continue
    else: finding(w, alternatives: D.alternatives(w))

pass = findings == []
```

The second test is the point of the rule: a word that you may not use on its own
is permitted inside a technical noun that your company approves. "Main" is not
approved and its alternative is "primary", but `main landing gear` is a technical
noun, and replacing "main" with "primary" there would give a term that no
glossary holds.

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `The base of the triangle is 5 cm.` | "base" as a technical noun, category 7 |
| pass | `Access to the base is permitted between 9 a.m. and 6 p.m.` | "base" as a technical noun, category 5 |
| pass | `Do the backup of the computer at regular intervals.` | "backup" as a technical noun, category 19 |
| pass | `Keep the backup file in a safe area.` | two-word technical noun |
| pass | `Retract the main landing gear.` | "main" inside a technical noun |
| pass | `...the relative angular positions of the rotor disks.` | "relative" inside a technical noun, category 7 |
| fail | `Make sure that the two spigots at the base of the unit engage.` | "base" refers to a surface → `bottom` |
| fail | `The laptop has these main parts:` | "main part" is not a technical noun → `primary parts` |
| fail | `Make sure that one person is available as backup.` | "backup" is not a technical noun here; use a different construction |

## Notes

- The last three examples show that the verdict depends on the meaning in
  context, which the glossary alone cannot give. A checker can only ask whether
  the word is inside a glossary term; a writer decides whether that term is the
  one that the sentence means.
- When the word is rejected, the finding should carry the dictionary
  alternatives, and rule 9.1 covers the case where no word-for-word replacement
  works.
