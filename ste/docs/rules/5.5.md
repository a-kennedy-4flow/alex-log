# Rule 5.5 — Notes

**Statement** (Issue 9, page 1-5-5)
> Write notes only to give information, not instructions.

- **Applies to:** every note in a procedure.
- **Needs:** structure (which blocks are notes), parser (imperative detection).
- **Decidable:** yes for the imperative and the sentence length; the "is this a
  limit or a requirement" half needs a small pattern list.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

for each note n of S:
    for each sentence s of n:
        if s is in the imperative:            finding(s, :instruction_in_a_note)
        if s contains a limit or a tolerance
           ("must not be more than", "minimum of", "maximum of", a value with a
            unit and a comparison):           finding(s, :limit_in_a_note)
        if s states a requirement or a
           prohibition ("must", "do not",
           "it is mandatory"):                finding(s, :requirement_in_a_note)
        if ste_word_count(s) > 25:            finding(s, :too_long, limit: 25)

pass = findings == []
```

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `NOTE: The gyroscope will become stable after approximately 15 seconds.` | information |
| pass | `NOTE: It is not necessary to remove the nameplate (33) from the flange (27).` | information |
| pass | `NOTE: You can use equivalent alternatives for these items.` | information |
| pass | `NOTE: The data collection is not completed. Thus, the statistics module can give incorrect results.` | two sentences, 6 and 8 words |
| fail | `NOTE: Make sure that the avionics ventilation system continues to operate correctly.` | imperative → it is a work step |
| fail | `NOTE: The leakage must not be more than 0.5 cc/minute.` | a limit → put it in the work step after the action |
| fail | `NOTE: When you connect the lines, do not bend them too much. If you bend the lines too much, you can cause damage to them.` | a prohibition with a consequence → it is a CAUTION |
| fail | `NOTE: Before closing the hatch, it is mandatory to ensure that no persons are in the crew rest compartment...` | a requirement with a risk of suffocation → it is a WARNING |

## The test that the standard gives

- Read the procedure without the notes.
- Make sure that the reader can do the procedure correctly without them.

If information is missing, move it out of the note into a work step, and repeat the
test. A checker cannot run this test, but it can report it: a note that contains a
verb in the imperative, a limit, or a prohibition is information that the procedure
needs, so it does not belong in a note.

## Notes

- The 25-word limit here is the exception to rule 5.1 and the same limit as rule
  6.3, because a note is descriptive text.
- In STE, notes belong in procedures. In descriptions they are permitted only when
  they are necessary for an illustration or a table.
