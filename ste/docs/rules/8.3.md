# Rule 8.3 — Parentheses

**Statement** (Issue 9, page 1-8-3)
> You can use parentheses:
> - To make references to illustrations or text
> - To include letters or numbers that identify items on an illustration or in a text
> - To identify the work steps in a procedure
> - To include abbreviations
> - To give the singular and plural forms of a noun at the same time
> - To explain words or a part of a sentence
> - To include an alternative.

- **Applies to:** every pair of parentheses in the text.
- **Needs:** text; judgment for the "explain" and "alternative" purposes.
- **Decidable:** heuristic. Five of the seven purposes have a recognizable shape;
  the other two are open.
- **Code:** not implemented.

## Discrete form

```
check(text) -> [report]

for each parenthesis pair p of text:
    if content(p) matches a reference   ("refer to ...", "10, Figure 1")      -> ok
    if content(p) is a number, a letter, or an alphanumeric identifier        -> ok
    if content(p) is a work step number at the start of a line               -> ok
    if content(p) is an abbreviation of the words before it                   -> ok
    if content(p) is "s" after a noun                                        -> ok
    else: report(p, :explanation_or_alternative, severity: :recommendation)

for each parenthesis pair p:
    if p is unbalanced:  finding(p, :unbalanced)

pass = only unbalanced parentheses fail
```

## The seven purposes, with the examples of the standard

| Purpose | Example |
| --- | --- |
| reference to an illustration or text | `Remove the valve (10, Figure 1).` `Install the cover (refer to paragraphs 2 thru 5).` |
| letters or numbers that identify items | `Disconnect the hoses (2) and (12) from the suction ejector (8).` |
| work step identifiers | `(1) Install the locking cap (4) on the body (8).` |
| abbreviations | `A Liquid Crystal Display (LCD) is a flat-panel display...` |
| singular and plural at the same time | `Before you do the test(s), install the component(s).` |
| explanation of words or part of a sentence | `Increase the pressure slowly (not more than 10 psi each minute).` |
| an alternative | `Open the left (right) access panel L42 (R42).` |

## Word count

Rules 8.5 and 8.6: text in parentheses counts as one word of its sentence, and the
words inside also make a sentence of their own that is counted separately.

## Notes

- The list is closed ("you can use parentheses: ..."), so in principle any other
  use is a finding. In practice the sixth purpose (explain a part of a sentence)
  covers almost anything, which is why this check should report rather than fail.
