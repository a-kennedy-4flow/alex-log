# Rule 6.6 — Paragraph length

**Statement** (Issue 9, page 1-6-5)
> Make sure that no paragraph has more than six sentences.

- **Applies to:** every paragraph of a descriptive text.
- **Needs:** text, structure (paragraph and sentence boundaries).
- **Decidable:** yes.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

for each paragraph p of S where S.mode(p) == :descriptive:
    n = number of sentences of p
    if n > 6: finding(p, count: n, limit: 6)

pass = findings == []
```

Sentence boundaries follow rule 8.4: in a vertical list, the colon of the lead-in
ends a sentence and each item is a sentence. A list therefore adds to the count of
its paragraph, which is what the fuel manifold example shows (a paragraph of one
sentence plus a five-item list).

## Examples

From the worked example of the standard, all of which pass:

| Paragraph | Sentences |
| --- | --- |
| the primary parts of the fuel manifold, with a list | 1 |
| the shut-off valve and the valve body, with a list | 2 |
| the spring, the packings, and the relief valve | 5 |
| the actuator assembly | 4 |
| the pressure transducer | 4 |
| the three fittings | 2 |

## Notes

- This is one of the few rules that a checker can decide with no dictionary, no
  glossary, and no parser: it needs only the paragraph and sentence structure. It
  is a good second rule to implement after 1.1, together with 5.1 and 6.3.
