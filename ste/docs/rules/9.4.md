# Rule 9.4 — Consistent style

**Statement** (Issue 9, page 1-9-8)
> When you select terminology or wording, always use a consistent style.

- **Applies to:** a whole document, mostly a procedure.
- **Needs:** document; synonym groups for terms, and a normalized form for work
  steps.
- **Decidable:** yes as a report: a checker can find work steps that do the same
  thing with different wording.
- **Code:** not implemented.

## Discrete form

```
check(document, glossary G) -> [finding]

# a) terminology, the same test as rule 1.11
for each synonym group g of G that the document uses with more than one term:
    finding(g, terms: ..., use: G.preferred(g))

# b) wording
group the work steps of the document by their action signature
    (main verb + object type + modifiers, with numbers and identifiers removed)
for each group with more than one distinct signature that means the same action:
    finding(group, :inconsistent_wording, wordings: ...)

pass = findings == []
```

## The example

Not STE:

```
1. Put the housing (8) in its installation position on the main body (9).
2. Lubricate the two bolts (10) with oil.
3. Install the two bolts (10) in the body (9).
4. Torque-tighten the two bolts to 4 Nm.
5. Put the transducer (11) on the body assembly (9).
6. Apply a small quantity of oil to the threads of the four bolts (12).
7. Attach the transducer (11) to the body assembly (9) with the four bolts (12).
8. Torque each of the four bolts (12) to 0.8 Nm.
```

Three inconsistencies, all of which a checker can find:

| Kind | Wordings |
| --- | --- |
| the same item, three names | "main body", "body", "body assembly" (item 9) |
| the same action, two verbs | "torque-tighten" and "torque" |
| the same action, two sentence patterns | "Lubricate the XX bolts with oil" and "Apply a small quantity of oil to the threads of the XX bolts" |

In STE, item (9) is "body assembly" everywhere, the verb is "torque" everywhere, and
the lubrication step uses one wording everywhere.

## Notes

- Both sentences of the lubrication example are correct STE on their own. That is
  what makes this rule different from the others: it fails a pair, not a sentence,
  so a checker must hold the document and not the string.
- The signature idea is worth keeping simple: the imperative verb plus the head
  nouns of its objects, with numbers and identifiers removed. Two work steps with
  the same head nouns and different verbs are the finding that this rule wants.
