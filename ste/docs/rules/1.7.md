# Rule 1.7 — Technical nouns as verbs

**Statement** (Issue 9, page 1-1-11)
> Do not use words that are technical nouns as verbs.

- **Applies to:** every technical noun of the glossary that the text uses.
- **Needs:** glossary, parser (part of speech).
- **Decidable:** with a tagger, plus one exception that needs the technical verb
  categories.
- **Code:** not implemented.

## Discrete form

```
check(text, glossary G) -> [finding]

for each word w of text that G lists as a technical noun:
    p = the part of speech that the sentence gives w
    if p is noun:                                  continue
    if p is adjective and w modifies another noun: continue   # "oil seal"
    if p is verb and G also lists w as a technical verb (rule 1.12): continue
    if p is verb: finding(w)

pass = findings == []
```

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `Apply oil to the steel surfaces.` | "oil" as a technical noun |
| pass | `If you think that snow will fall, ...` | "snow" as a technical noun |
| pass | `If the surface is hard, use a carbide drill.` | "drill" as a technical noun (category 3) |
| pass | `Drill a hole at the intersection of the two lines.` | "drill" is also a technical verb (rule 1.12, category 1a) |
| fail | `Oil the steel surfaces.` | "oil" as a verb |
| fail | `If you think it will snow, ...` | "snow" as a verb |

## Out of scope

- A **dictionary** word used as the wrong part of speech — rule 1.2.
- A technical **verb** used as a noun — rule 1.13.

## Notes

- The overlap case ("drill", "load", "store", "process", "update", "filter") is
  not an error: a word can be in a technical noun category and a technical verb
  category at the same time. A glossary therefore has to record the categories,
  not only the term, or this rule will report false findings.
- The repair is usually a different sentence construction that keeps the word as
  a noun (`Apply oil to`, `snow will fall`), which is rule 9.1.
