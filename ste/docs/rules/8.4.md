# Rule 8.4 — The colon in a vertical list

**Statement** (Issue 9, page 1-8-4)
> In a vertical list, a colon (:) has the same effect on word count as a period and
> shows the end of a sentence.

- **Applies to:** the word count of rules 5.1, 6.3, and 6.6, not to a text on its
  own.
- **Needs:** structure (the lead-in sentence and the items of a vertical list).
- **Decidable:** yes. This is a counter rule.
- **Code:** not implemented.

## Discrete form

```
sentences(text, structure S) -> [sentence]

for each vertical list l of S:
    the lead-in text up to and including the colon is one sentence
    each item of l is one sentence

limit per sentence:
    20 words in procedural writing      # rule 5.1
    25 words in descriptive writing      # rule 6.3
```

## The example

```
To extinguish a possible fire, portable fire extinguishers are installed
in these areas:                                             (13 words)
     - The cockpit                                           (2 words)
     - The cabin                                             (2 words)
     - The cabin sub-compartment                             (3 words)
     - The crew rest compartment.                            (4 words)
```

## What it changes

| Without this rule | With this rule |
| --- | --- |
| the list above is one sentence of 24 words, which fails rule 5.1 | five sentences of 13, 2, 2, 3, and 4 words, which all pass |
| a paragraph with a list counts as one sentence | rule 6.6 counts the lead-in and each item |

## Notes

- This is why a checker needs the document structure and not only the string: the
  same characters count differently depending on whether the lines are a vertical
  list or a run of text.
- Together with rules 8.5, 8.6, and 8.7, this rule defines the STE word count.
  Implement all four in one place (`Ste.WordCount`) and let rules 5.1, 6.3, 6.6,
  2.1, and 1.9 use it.
