# Rule 3.1 — Verb forms of the dictionary

**Statement** (Issue 9, page 1-3-1)
> Use only the verb forms that are given in the dictionary.

- **Applies to:** every verb of the text.
- **Needs:** dictionary, parser (to know that the word is used as a verb).
- **Decidable:** mostly. Membership in the listed forms is exact; deciding that a
  token is a verb is not.
- **Code:** not implemented. `Ste.Dictionary` keeps the `forms` of each entry.

## Discrete form

```
check(text, dictionary D, glossary G) -> [finding]

for each verb v of text:
    if D approves v as a verb (headword or listed form):  continue
    if G lists v as a technical verb, in a form that the same rules permit: continue
    else: finding(v, approved_forms: D.forms(stem(v)))

pass = findings == []
```

## What the dictionary gives

```
REMOVE (v)      GIVE (v)
REMOVES         GIVES
REMOVED,        GAVE,
REMOVED         GIVEN
```

Regular verbs add `-ed` for the simple past and the past participle, and the
dictionary prints the past participle twice for that reason. Irregular verbs,
irregular auxiliary verbs, and defective modal verbs are listed with their own
forms. A form that the entry does not print is not approved, even when English
allows it.

## Relation to the other verb rules

| Rule | Question |
| --- | --- |
| 3.1 | is this **form** in the dictionary? |
| 3.2 | is this **tense** one of the six that STE permits? |
| 3.3 | is the past participle used as an adjective and not as a verb? |
| 3.4 | does an auxiliary verb build a construction that STE does not permit? |
| 3.5 | is the `-ing` form a technical noun or a modifier in one? |
| 1.4 | the same membership test as 3.1, stated in section 1 for verbs and adjectives together |

## Notes

- Rules 1.4 and 3.1 overlap on purpose: 1.4 is about the dictionary as a word
  list, 3.1 about writing verbs. One implementation can serve both, and the
  finding should name both rules.
