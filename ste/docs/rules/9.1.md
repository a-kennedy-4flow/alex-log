# Rule 9.1 — Different sentence constructions

**Statement** (Issue 9, page 1-9-1)
> Use a different sentence construction to write a sentence when a word-for-word
> replacement is not sufficient.

- **Applies to:** the repair of a finding, not the text.
- **Needs:** judgment.
- **Decidable:** no. This rule tells a writer what to do after another rule fails.
- **Code:** not implemented, and should not be. Its place in a checker is in the
  suggestion that a finding carries.

## Discrete form

```
suggest(finding, dictionary D) -> suggestion

w = the rejected word of the finding
alternatives = D.alternatives(w)

if an alternative has the same part of speech as w:
    suggest(:word_for_word, alternative)          # "acceptable" -> "permitted"
else if an alternative has a different part of speech:
    suggest(:new_construction, alternative)       # "operable" -> "can operate"
else:
    suggest(:new_construction, :no_alternative)   # rewrite the sentence
```

## Examples

| Rejected | Alternatives | Repair |
| --- | --- | --- |
| `A value of 2 mm is acceptable.` | PERMITTED (adj), SATISFACTORY (adj), SERVICEABLE (adj) | word for word: `A value of 2 mm is permitted.` |
| `Make sure that the valve is operable.` | OPERATE (v) | new construction: `Make sure that the valve can operate.` |
| `For this procedure, make sure that one person is available as backup.` | none that fits | new construction: `Two persons are necessary to do this procedure.` |

## The warning that comes with it

When you replace a word, make sure that the alternative does not change the meaning
of the sentence. If the meaning changes, select a different word or use a different
sentence construction. This is why a checker must offer alternatives and never apply
them automatically.

## Notes

- The longer example in the standard (a table of crack lengths and flight hours)
  ends with a repair that no word-level tool could produce: move the instruction
  into the heading of the table, because the table already carries the information.
  The primary objective is that the reader immediately understands each sentence.
