# Rule 3.4 — Auxiliary verbs

**Statement** (Issue 9, page 1-3-3)
> Do not use auxiliary verbs to make complex verb constructions.

- **Applies to:** every verb group of the text that has more than one word.
- **Needs:** parser.
- **Decidable:** yes for the patterns that the standard gives.
- **Code:** not implemented.

## Discrete form

```
check(text) -> [finding]

for each verb group g of text with an auxiliary:
    if g is "will" + base form:                   continue      # simple future
    if g is a modal + base form:                  continue      # "you can adjust"
    if g is have/has/had + past participle:       finding(g, :perfect_tense)
    if g is be + past participle:                 finding(g, :passive)
    if g is modal + be + past participle:         finding(g, :modal_passive)
    if g is be + "to be" + past participle:       finding(g, :obligation_passive)
    if g is be + "-ing":                          finding(g, :progressive)

pass = findings == []
```

## Examples

| Not STE | STE | Pattern |
| --- | --- | --- |
| `The operator has adjusted the linkage.` | `The operator adjusted the linkage.` | present perfect |
| `The seat is to be installed before you install the cushion.` | `Before you install the cushion, install the seat.` | obligation, passive |
| `The volume control can be adjusted.` | `You can adjust the volume control.` | modal, passive |
| `The temperature must be adjusted.` | `Adjust the temperature.` | modal, passive, procedural |
| `The sleeve will be adjusted by the robot.` | `The robot will adjust the sleeve.` | future, passive |

## Notes

- The findings of this rule and of rule 3.6 come from the same constructions. Keep
  them apart by what they report: 3.4 reports the **construction** (an auxiliary
  built a tense or a voice that STE does not have), 3.6 reports the **voice** and
  asks whether the agent is known. A sentence usually fails both, and one repair
  fixes both.
- `can`, `must`, and `will` are approved words and are not the problem; the
  problem is a modal plus `be` plus a past participle. A checker that flags every
  modal will be wrong on `You can adjust the volume control.`
