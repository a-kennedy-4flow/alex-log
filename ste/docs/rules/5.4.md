# Rule 5.4 — Conditions before commands

**Statement** (Issue 9, page 1-5-4)
> When there is a condition that the reader must know about first, start the
> instruction with a descriptive statement. Then, divide that descriptive statement
> from the command with a comma.

- **Applies to:** every instruction that has a condition.
- **Needs:** parser (to find the conditional clause and its position).
- **Decidable:** yes.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

for each sentence s of S where S.kind(s) == :work_step:
    c = the conditional or temporal clause of s ("if ...", "when ...", "while ...",
                                                 "before ...", "after ...")
    if c is nil:                                    continue
    if c comes before the command and a comma
       divides them:                                continue
    if c comes before the command and no comma:     finding(s, :missing_comma)
    if c comes after the command:                   finding(s, :condition_after_command)

pass = findings == []
```

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `When the light comes on, set the switch to NORMAL.` | condition first, comma |
| pass | `When the surface is dry, apply the primer.` | condition first, comma |
| pass | `If the Constant Speed Drive (CSD) does not operate correctly, disconnect it from the gearbox.` | condition first, comma |
| fail | `Set the switch to NORMAL when the light comes on.` | condition after the command |
| fail | `Apply the primer when the surface is dry.` | condition after the command |
| fail | `Disconnect the Constant Speed Drive (CSD) from the gearbox, if it does not operate correctly.` | condition after the command |

## The comma changes the meaning

Both of these are correct STE and they mean different things:

- `If the Constant Speed Drive (CSD) does not operate correctly, disconnect it from
  the gearbox.` — "correctly" modifies "operate".
- `If the Constant Speed Drive (CSD) does not operate, correctly disconnect it from
  the gearbox.` — "correctly" modifies "disconnect".

So a checker must never move or insert a comma on its own; it reports the position
and lets the writer decide which reading is meant.
