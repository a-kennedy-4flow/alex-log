# Rule 5.2 — One instruction per sentence

**Statement** (Issue 9, page 1-5-2)
> Write only one instruction in each sentence unless two or more actions occur at
> the same time.

- **Applies to:** every sentence of a procedure.
- **Needs:** parser (to count the imperative verbs), judgment (do the actions
  occur at the same time?).
- **Decidable:** the detection yes, the exception no.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

for each sentence s of S where S.mode(s) == :procedural:
    verbs = imperative verbs of s at the top level
    if length(verbs) <= 1: continue
    else: finding(s, verbs: verbs, question: "do these actions occur at the same time?")

pass = findings == []     # a writer resolves each finding as :simultaneous or splits it
```

Because the exception is a fact about the machine, not about the sentence, a
checker cannot close it. The useful output is a question with the verbs named, and
a way to record the answer (a per-project allow list of simultaneous pairs:
`cut and remove`, `remove and discard`, `hold ... and install`).

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `(1) Set the TEST switch to the middle position.` `(2) Make sure that all the switches on the control panel are OFF.` | two work steps |
| pass | `Hold the panel in its open position and install the fastener.` | the actions occur at the same time |
| pass | `Slowly extend the rod fully and make sure that it does not touch other parts.` | at the same time |
| pass | `Cut and remove the wire.` | at the same time |
| pass | `Remove and discard the seal.` | at the same time |
| fail | `Set the TEST switch to the middle position and release the SHORT-CIRCUIT TEST switch.` | two actions, not at the same time → two work steps |

## More than one sentence in a work step

The standard permits it in two cases:

- when the actions occur at the same time:
  `Make sure that the locking torque of each of the four bolts (6) is a minimum of
  0.30 Nm. Then, torque each of the four bolts (6) to 4.20 Nm.`
- when a result occurs immediately after an action:
  `Measure the leakage from the outlet port. The leakage must not be more than
  0.5 cc/minute.`

The second case is also the repair that rule 5.5 asks for when a limit is written
as a note.
