# Rule 7.2 — Start with a command or a condition

**Statement** (Issue 9, page 1-7-3)
> Start a safety instruction with a clear and accurate command or condition.

- **Applies to:** every safety instruction.
- **Needs:** structure, parser.
- **Decidable:** yes.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

for each safety instruction b of S:
    s = the first sentence of b after the signal word
    if s starts with an imperative verb (including "DO NOT"):        continue
    if s starts with a condition clause ("if", "when", "while",
       "before", "after") that a comma divides from a command:       continue
    else: finding(b, :does_not_start_with_a_command_or_condition)

pass = findings == []
```

## Examples

| Verdict | Text | Starts with |
| --- | --- | --- |
| pass | `WARNING: DO NOT SWALLOW THE SOLVENT. ALWAYS MAKE SURE THAT YOU KNOW THE SAFETY PRECAUTIONS AND FIRST AID INSTRUCTIONS FOR SOLVENTS. SOLVENTS ARE POISONOUS AND CAN CAUSE INJURY OR DEATH.` | a negative command |
| pass | `CAUTION: DO NOT USE BLEACH OR CLEANSERS THAT CONTAIN CHLORINE TO CLEAN THE UNIT. THESE CLEANING AGENTS CAN CAUSE CORROSION.` | a negative command |
| pass | `WARNING: WHILE YOU USE THE SPRAY PAINT, POINT THE SPRAY AWAY FROM YOUR FACE. THE SPRAY PAINT CAN CAUSE INJURY TO YOUR EYES.` | a condition, then a command |
| pass | `CAUTION: WHEN YOU ASSEMBLE THE UNIT, DO NOT LET THE PARTS FALL. IF THEY FALL, PERMANENT DAMAGE TO THE PARTS CAN OCCUR.` | a condition, then a command |
| fail | `CAUTION: EXTREME CLEANLINESS OF OXYGEN TUBES IS IMPERATIVE.` | a statement |

## Notes

- This is rule 5.3 and rule 5.4 applied to safety instructions, so one
  implementation can serve all three: an instruction starts with an imperative, or
  with a condition and a comma.
- Rule 4.3 adds the list form: in a vertical list inside a safety instruction, each
  item repeats the negative command (`- DO NOT USE THE APU LINE AS A HANDLE.`)
  instead of hanging under a shared `DO NOT:`.
