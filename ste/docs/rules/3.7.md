# Rule 3.7 — How to describe an action

**Statement** (Issue 9, page 1-3-9)
> Use an approved verb to describe an action, not a noun or other parts of speech.

- **Applies to:** every sentence that describes an action.
- **Needs:** dictionary, parser.
- **Decidable:** heuristic. The pattern to find is a nominalization plus a light
  verb, which is a small set of shapes.
- **Code:** not implemented.

## Discrete form

```
check(text, dictionary D) -> [finding]

for each sentence s of text:
    for each pattern p in {light verb + nominalization,
                           "before/after the <nominalization> of"}:
        if s matches p and D approves the verb v that the nominalization
           comes from: finding(s, use: v)

pass = findings == []
```

## Patterns

| Shape | Example | Repair |
| --- | --- | --- |
| light verb + noun of action | `The ohmmeter gives an indication of 450 ohms.` | `The ohmmeter shows 450 ohms.` |
| preposition + noun of action + "of" | `Before the removal of the unit, make sure that the power supply is OFF.` | `Before you remove the unit, make sure that the power supply is OFF.` |

Light verbs to look for: give, do, make, take, provide, perform, carry out (the
last two are not approved anyway).

## The other half of the rule

> If a word is not approved as a verb in the dictionary, do not use it as a verb.
> Use a different sentence construction to give the same information.

`Check the laptop battery.` → `Do a check of the laptop battery.`

That direction is the same test as rule 1.2, and it goes the opposite way from the
first half: here the noun construction is the correct answer, because "check" is
not an approved verb. So the rule is not "always prefer a verb": it is "prefer an
approved verb when one exists, and change the construction when one does not".

## Notes

- Both examples of the first half are STE already, and the standard says so: they
  are correct sentences that a direct verb makes clearer. A finding of this rule
  is therefore a recommendation and should be reported with a lower severity than
  a finding of rule 1.1 or 5.1.
