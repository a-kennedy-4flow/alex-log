# Rule 1.1 — Which words can you use?

**Statement** (Issue 9, page 1-1-2)
> Use words that are:
> - Approved in the dictionary
> - Technical nouns
> - Technical verbs.

- **Applies to:** every word of procedural and descriptive text.
- **Needs:** dictionary, glossary.
- **Decidable:** yes. The glossary decides the technical nouns and verbs, so the
  verdict is only as good as the glossary that the caller supplies.
- **Code:** `Ste.Rules.Rule1_1`, `lib/ste/rules/rule1_1.ex`.

## Discrete form

```
check(text, dictionary D, glossary G) -> [finding]

for each token t of text with kind :word:
    if t (or the longest phrase starting at t) is permitted: continue
    else: finding(t)

permitted(w) =
    D approves w as any part of speech          # headword, listed verb or
                                                # adjective form, or plural of an
                                                # approved countable noun
  or w is a technical noun of G                 # rule 1.5
  or w is a technical verb of G                 # rule 1.12
  or w is hyphenated and every part is permitted   # rule 8.7

pass = findings == []
```

Phrases are matched before single words, so the dictionary entries `MAKE SURE`
and `AFT OF` and glossary terms such as `main landing gear` are one unit.

## Out of scope

- Whether the word is used as the approved **part of speech** — rule 1.2.
- Whether it carries its approved **meaning** — rule 1.3.
- Whether the **form** of the verb or adjective is one the dictionary lists —
  rule 1.4.
- Whether a technical noun is used as a verb — rule 1.7.

## Elements that are not vocabulary

Skipped, because rule 8.6 lists them as elements that count as one word and that
you cannot change: numbers, numbers with a unit of measurement, numbers written
in words, abbreviations, alphanumeric identifiers, quoted text, and text in
uppercase letters.

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `Obey the safety instructions.` | all words approved |
| pass | `Install the engine.` | "engine" is a technical noun (rule 1.5, category 1) |
| pass | `Ream the hole to a diameter of 10 mm.` | "ream" is a technical verb (rule 1.12, category 1a) |
| pass | `Do the backup of the laptop at regular intervals.` | "backup" and "laptop" are technical nouns (category 19) |
| pass | `Release the SHORT-CIRCUIT TEST switch.` | uppercase text is quoted text (rule 8.6) |
| pass | `Follow the safety instructions.` | "follow" is approved; the wrong meaning is rule 1.3 |
| fail | `A value of 2 mm is acceptable.` | "acceptable" is not approved → PERMITTED, SATISFACTORY, SERVICEABLE |
| fail | `The accuracy of the adjustment can change.` | "accuracy" is not approved → PRECISION |
| fail | `Make sure that the valve can operate.` | "valve" needs a company glossary |

## Notes

- A word that the dictionary lists as **not approved** gets its approved
  alternatives as suggestions. A word that the dictionary does not list at all
  gets a message that says to add it to the glossary if it is a technical noun
  or verb of the subject field.
- Rule 1.5 says its category lists are examples and not a full list, so
  `priv/technical_terms.json` is a starting point, not a decision.
