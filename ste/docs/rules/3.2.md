# Rule 3.2 — Verb forms and tenses

**Statement** (Issue 9, page 1-3-2)
> Use only these verb forms and tenses of verbs:
> - The infinitive form
> - The imperative form (command form)
> - The simple present tense
> - The simple past tense
> - The simple future tense
> - The past participle form (as an adjective).

- **Applies to:** every finite verb group of the text.
- **Needs:** parser (verb group detection).
- **Decidable:** yes for the tenses that the standard names, because each is a
  fixed pattern of auxiliary plus form.
- **Code:** not implemented.

## Discrete form

```
check(text) -> [finding]

for each verb group g of text:
    if form(g) in {infinitive, imperative, simple present, simple past,
                   simple future, past participle as adjective}: continue
    else: finding(g, form: form(g))

pass = findings == []
```

## The patterns that fail

| Pattern | Tense | Example |
| --- | --- | --- |
| have/has + past participle | present perfect | `The operator has adjusted the linkage.` → `The operator adjusted the linkage.` |
| had + past participle | past perfect | `had adjusted` |
| is/are/was/were + `-ing` | present or past progressive | `is adjusting`, `When you are doing this procedure` → `When you do this procedure` |
| will have + past participle | future perfect | any |
| any other multi-auxiliary group | - | see rule 3.4 |

## The six forms that pass

| Form | Regular | Irregular |
| --- | --- | --- |
| infinitive | (to) adjust | (to) give |
| imperative | Adjust + object | Give + object |
| simple present | you/we/they adjust, it adjusts | you/we/they give, it gives |
| simple past | adjusted | gave |
| simple future | will adjust | will give |
| past participle as adjective | the adjusted linkage | the given information |

## Notes

- The list of six is the whole rule: anything else is a finding, so the check does
  not need a list of rejected tenses, only a recognizer for the six permitted
  ones. That is the safer direction, because a new auxiliary pattern then fails
  by default.
- The past participle entry is a form, not a tense, and it only passes when it is
  an adjective; rule 3.3 gives the positions where that is true.
