# Rule 3.6 — Active voice

**Statement** (Issue 9, page 1-3-5)
> Use the active voice. In descriptive writing, you can use the passive voice only
> when the agent is unknown.

- **Applies to:** every sentence.
- **Needs:** parser, structure (procedural or descriptive), judgment (is the agent
  unknown?).
- **Decidable:** the detection yes, the exception no. A checker can find every
  passive; only a person can say that the agent is unknown.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

for each sentence s of text:
    if s is not passive:                       continue
    if S.mode(s) == :procedural:               finding(s, :passive_in_procedure)
    if s names an agent (usually after "by"):  finding(s, :agent_is_known, agent: ...)
    else: finding(s, :passive_agent_unknown, severity: :question)

pass = findings without severity :question == []
```

The third case is the standard's exception and the reason it cannot be decided:
`During transmission, the data was corrupted.` is correct STE because nothing
corrupted the data that the writer can name, and rewriting it as `Transmission
corrupted the data.` makes it technically wrong. Report it, do not fail it.

## How to detect the passive

The standard's own test: ask "by whom or by what?". If the text answers, it is
passive, and the object of "by" is the agent.

| Passive | Agent |
| --- | --- |
| `The safety procedures are given by the manufacturer.` | manufacturer |
| `The main gear leg is held by the side stay.` | side stay |
| `The dimensions are given in the table.` | none in the sentence |
| `The main gear leg is held in its position.` | none in the sentence |

## The four repairs of the standard

| Method | Not STE | STE |
| --- | --- | --- |
| 1. the agent becomes the subject | `The circuits are connected by a switching relay.` | `A switching relay connects the circuits.` |
| 2. an infinitive becomes the active verb | `These values are used by the computer to calculate the energy consumption.` | `The computer calculates the energy consumption from these values.` |
| 3. in procedures, use the imperative | `Oil and grease are to be removed with a degreasing agent.` | `Remove oil and grease with a degreasing agent.` |
| 4. no agent given: use "you" or "we" | `On the ground, the valve can be opened with the override handle.` | `On the ground, you can open the valve with the override handle.` |

## Notes

- Method 3 is why this rule needs the structure: the same passive sentence has a
  procedural repair and a descriptive repair, and the checker cannot choose
  between `Adjust the volume control.` and `You can adjust the volume control.`
- A past participle after "to be" that describes a condition is **not** passive
  (rule 3.3), so a detector must not report `When the unit is fully disassembled`.
