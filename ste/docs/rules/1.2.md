# Rule 1.2 — Part of speech

**Statement** (Issue 9, page 1-1-2)
> Use approved words from the dictionary only as the specified part of speech.

- **Applies to:** every word of the text that the dictionary approves.
- **Needs:** dictionary, parser (part-of-speech tagging).
- **Decidable:** with a tagger. The dictionary side is exact
  (`Ste.Dictionary.approved?/2`); the reading of the sentence is not.
- **Code:** not implemented.

## Discrete form

```
check(text, dictionary D) -> [finding]

for each word w of text, with the part of speech p that the sentence gives it:
    if D does not list w:                    continue   # rule 1.1 handles it
    if D approves w as p:                    continue
    else: finding(w, p, approved_as: D.approved_as(w))

pass = findings == []
```

## Out of scope

- A word that the dictionary does not list at all — rule 1.1.
- The meaning of a word that is used as the correct part of speech — rule 1.3.
- Replacing the word once it is rejected — rule 9.1 (word-for-word replacement is
  possible only when an alternative has the same part of speech).

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `Test B is an alternative to test A.` | "test" is an approved noun |
| pass | `A dim light comes on.` | "dim" is an approved adjective |
| pass | `Clean the inner surface of the container.` | "clean" is approved as a verb and as an adjective |
| pass | `Make sure that the area is clean.` | the same word as an adjective |
| fail | `Test the system for leaks.` | "test" is not an approved verb → `Do the leak test of the system.` |
| fail | `Dim the lights.` | "dim" is not an approved verb → `Set the lights to the dim position.` |
| fail | `Be careful not to damage the sleeve.` | "damage" is an approved noun, not a verb (rule 9.2) |
| fail | `When you work with cleaning agents...` | "work" is an approved noun, not a verb |

## Notes

- The check needs a part-of-speech decision per token, and the standard itself
  says the position of the word in the sentence shows its function. A tagger that
  is wrong about the position turns a correct sentence into a finding, so a
  finding of this rule should carry the tagger's reading so a writer can see why.
- A useful cheap subset: an approved noun that is immediately followed by an
  article or a determiner at the start of a work step is being used as an
  imperative verb (`Test the system`, `Check the battery`). This subset needs no
  full tagger and catches the errors that the standard gives as examples.
