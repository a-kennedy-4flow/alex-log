# Rule 5.3 — The imperative form

**Statement** (Issue 9, page 1-5-3)
> Write instructions in the imperative (command) form.

- **Applies to:** every instruction, that is every work step and every command in
  a safety instruction.
- **Needs:** parser, structure (which sentences are instructions).
- **Decidable:** yes, when the structure says which sentences are instructions.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

for each sentence s of S where S.kind(s) == :work_step:
    if the main verb of s is imperative:                     continue
    if s starts with a condition and the command comes after
       the comma and is imperative:                          continue   # rule 5.4
    else: finding(s, :not_imperative)

for each sentence s of S where S.kind(s) == :work_step:
    if s contains "must" before an imperative and S.kind(s) is not a
       safety instruction and s gives no important condition:
        finding(s, :must_before_imperative)

pass = findings == []
```

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `Set the switch to ON.` | imperative |
| pass | `Increase the pressure to 60 psi.` | imperative |
| pass | `WARNING: IF YOU MUST CUT THE WIRE, ALWAYS USE A PROTECTIVE MASK. PIECES OF WIRES CAN CAUSE INJURY.` | "must" is permitted in a safety instruction |
| fail | `The test can be continued.` | → `Continue the test.` |
| fail | `Oil and grease are to be removed with a degreasing agent.` | → `Remove oil and grease with a degreasing agent.` |
| fail | `Before you remove the clamp, you must disconnect the hose.` | → `Before you remove the clamp, disconnect the hose.` |

## Why the rule exists

If an instruction is not in the imperative, the reader does not know:

- if it is important to do the work step,
- if a different person did the work step,
- if a different person must do the work step in the future.

## Notes

- The findings of this rule and of rule 3.6 have the same source in procedures: a
  passive instruction. Report both, and let the repair be the same imperative.
- The mirror of this rule is rule 6.x and rule 5.5: descriptive text and notes must
  **not** contain the imperative. A checker needs the structure to tell which of
  the two verdicts to give.
