# Rule 6.3 — Sentence length in descriptions

**Statement** (Issue 9, page 1-6-4)
> Write short sentences. Use a maximum of 25 words in each sentence.

- **Applies to:** every sentence of a descriptive text, and every sentence of a
  note (rule 5.5).
- **Needs:** text, structure.
- **Decidable:** yes, with the word count of rules 8.4 to 8.7.
- **Code:** not implemented; `Ste.Text` implements the tokenizing half.

## Discrete form

```
check(text, structure S) -> [finding]

for each sentence s of S where S.mode(s) == :descriptive or S.kind(s) == :note:
    n = ste_word_count(s)
    if n > 25: finding(s, count: n, limit: 25)

pass = findings == []
```

The limit is higher than the procedural limit of rule 5.1 because descriptive text
is more complex than procedural text.

## Examples with their counts

| Verdict | Text | Count |
| --- | --- | --- |
| pass | `During the approach to the runway, deviation pointers in the course indicators show the pilot in which direction the aircraft must go.` | 22 |
| fail | `A smartphone is a cellular telephone that has an integrated computer and many other functions, such as an operating system, internet browsing as well as the ability to run software applications.` | 31 → two sentences of 15 and 16 |

## Notes

- The same counter serves rules 5.1, 6.3, and 5.5; only the limit and the selection
  of sentences change. Implement one `Ste.WordCount` and give it the limit.
- A vertical list changes what a sentence is: rule 8.4 makes the colon of the
  lead-in a full stop, and each item is a sentence of its own with the same 25-word
  limit.
