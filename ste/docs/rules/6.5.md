# Rule 6.5 — One topic per paragraph

**Statement** (Issue 9, page 1-6-5)
> Make sure that each paragraph has only one topic.

- **Applies to:** every paragraph of a descriptive text.
- **Needs:** judgment; a heuristic can give a signal.
- **Decidable:** no. A lexical measurement can only report a suspicion.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [report]

for each paragraph p of S:
    subjects = the grammatical subject of each sentence of p
    if the subjects fall into two groups that share no key word:
        report(p, :possibly_more_than_one_topic, groups: ...)

pass = always true; this rule reports
```

## Signals worth reporting

| Signal | Why |
| --- | --- |
| the subjects of the sentences share no key word | rule 6.2 says the key words carry the topic |
| a paragraph names two different units or systems as subjects | the fuel manifold example gives one paragraph per part |
| a paragraph has more than six sentences | rule 6.6, usually the same problem |

## Notes

- Rule 4.1 asks the same thing of a sentence ("each sentence has only one topic")
  and rule 6.1 of the text as a whole. The three form a hierarchy: one topic per
  sentence, one topic per paragraph, information given gradually across the text.
- Because the verdict is a judgment, the useful artifact is a review checklist item
  rather than a build failure.
