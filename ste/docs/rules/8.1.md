# Rule 8.1 — Punctuation marks

**Statement** (Issue 9, page 1-8-2)
> You can use all standard English punctuation marks but not the semicolon (;).

- **Applies to:** every character of the text.
- **Needs:** text.
- **Decidable:** yes, exactly. This is the simplest rule in the standard.
- **Code:** not implemented.

## Discrete form

```
check(text) -> [finding]

for each semicolon at position i of text:
    if the semicolon is inside quoted text that you cannot change (rule 8.6):
        continue
    else: finding(at: i, :semicolon)

pass = findings == []
```

## Examples

| Verdict | Text | Repair |
| --- | --- | --- |
| fail | `(1) Examine the removed parts; replace the damaged ones.` | `(1) Examine the removed parts for damage.` `(2) Replace the damaged part(s).` |
| fail | `The battery is not user-replaceable; it can only be replaced by an approved service station.` | `Users cannot replace the battery. Only specialists at approved service stations can replace it.` |

## Notes

- The reason the standard gives is that the semicolon lets you write very long
  sentences and is not easy to use correctly. The repair is always two sentences,
  which rule 4.4 then connects with "and", "but", "then", or "thus" if the relation
  needs to be explicit.
- The exception for quoted text matters in practice: a placard or a label that
  contains a semicolon counts as one word (rule 8.6) and cannot be changed.
- STE gives no other punctuation rules and points at external style manuals (Chicago,
  Gregg, GPO, Swan, Kirkman), so a checker should not invent punctuation findings
  beyond rules 8.1, 8.2, and 8.3.
