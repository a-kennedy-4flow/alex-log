# Rule 3.5 — The "-ing" form

**Statement** (Issue 9, page 1-3-4)
> Use the "-ing" form of a verb only as a technical noun or as a modifier in a
> technical noun.

- **Applies to:** every word of the text that ends in `-ing`.
- **Needs:** dictionary, glossary.
- **Decidable:** yes. The permitted cases are three closed lists plus the
  glossary.
- **Code:** not implemented.

## Discrete form

```
check(text, dictionary D, glossary G) -> [finding]

for each word w of text that ends in "-ing":
    if D approves w (noun, adjective, pronoun, or preposition):  continue
    if G lists w as a technical noun:                            continue
    if G lists a technical noun in which w is a modifier and the
       text uses that technical noun here:                       continue
    else: finding(w)

pass = findings == []
```

## The approved `-ing` words of the dictionary

| Part of speech | Words |
| --- | --- |
| noun | lighting, opening, routing, servicing |
| adjective | mating, missing, remaining |
| pronoun | something |
| preposition | during |

## The two permitted glossary cases

| Case | Examples |
| --- | --- |
| the `-ing` form is a technical noun, often in a title or heading | Cleaning, Testing and Fault Isolation, Handling, Packaging, Shipping, Troubleshooting |
| the `-ing` form is a modifier in a technical noun, related to the function of a system, component, part, tool, material, or equipment | air-conditioning system, degreasing agent, grinding wheel, polishing disc, sanding machine, switching relay, welding torch |

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `Install the switching relay.` | modifier in a technical noun |
| pass | `Refer to Testing and Fault Isolation, page block 1001.` | technical noun in a title |
| pass | `During this procedure, obey all the safety precautions.` | "during" is an approved preposition |
| fail | `When you are doing this procedure, obey all the safety precautions.` | → `When you do this procedure, ...` |
| fail | `Mechanics wearing insufficient protective clothing and opening containers containing hazardous materials...` | a chain of `-ing` modifiers; the repair is a vertical list of work steps |

## Notes

- The reason the standard gives is ambiguity: the same `-ing` word can be a verb,
  an adjective, a noun, or the head of a dependent clause, and a reader cannot
  tell which. A finding is most useful when it says which of the four readings the
  checker saw.
- This rule is why rule 1.4 refuses `removing`: the form is not in the dictionary
  and this rule gives the only two ways to use one.
