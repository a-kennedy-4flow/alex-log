# Rule 1.12 — Technical verbs

**Statement** (Issue 9, page 1-1-13)
> You can use verbs that you can include in a technical verb category.

- **Applies to:** every verb of the text that the dictionary does not approve.
- **Needs:** glossary (with categories).
- **Decidable:** yes, against a glossary.
- **Code:** not implemented on its own; `Ste.Glossary` holds the categories and
  `Ste.Rules.Rule1_1` consumes them.

## Discrete form

```
check(text, dictionary D, glossary G) -> [finding]

for each verb v of text:
    if D approves v as a verb:                    continue
    if G lists v as a technical verb:             continue
    else: finding(v)

pass = findings == []
```

Technical verbs must obey the same rules as other approved verbs (section 3), so
a technical verb that passes this rule can still fail rules 3.2 through 3.5.

## The four categories

1. Manufacturing processes
   - a) remove material, b) add material, c) attach material,
   - d) change the mechanical strength, structure, or physical properties,
   - e) change the surface finish, f) change the shape
2. Computer processes and applications
   - a) input and output, b) user interface and application, c) system operations
3. Instructions and information for applicable subject fields
   - a) engineering, mathematical, and scientific, b) medical,
   - c) civil and military operations, d) navigation,
   - e) automotive and railway, f) energy, oil, and gas
4. Law and regulations

The example terms of each category are in `priv/technical_terms.json`.

## Examples

| Verdict | Text | Why |
| --- | --- | --- |
| pass | `Ream the hole.` | category 1a |
| pass | `Reboot the system.` | category 2c |
| pass | `Comply with the safety regulations.` | category 4 |
| fail | `Gronk the fitting.` | in no category and in no glossary |

## Notes

- Some category-4 verbs are listed with their scope in parentheses: `meet (a
  requirement)`, `waive (for inspection and requirements)`. The glossary should
  keep that scope, because it is a restriction on the meaning (rule 1.3).
- A verb that is also a technical noun is normal; see rule 1.7 for how the two
  interact.
