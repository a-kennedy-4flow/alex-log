# Rule 1.14 — Spelling

**Statement** (Issue 9, page 1-1-14)
> Use American English spelling unless other official directives tell you
> differently.

- **Applies to:** every word of the text.
- **Needs:** text, plus a British-to-American spelling table.
- **Decidable:** yes.
- **Code:** not implemented.

## Discrete form

```
check(text, spellings S, official_directive?) -> [finding]

if official_directive? is set: return []      # "unless other official
                                              #  directives tell you differently"
for each word w of text:
    if S maps w to an American spelling a and a != w:  finding(w, use: a)

pass = findings == []
```

The dictionary itself uses American English spelling as defined in
Merriam-Webster, and the punctuation of its examples obeys American English
rules, so the dictionary is the first source of truth: a word that the dictionary
approves is spelled the way the dictionary spells it.

## Patterns for the table

| British | American | Example in the dictionary |
| --- | --- | --- |
| -our | -or | colour → color |
| -re | -er | centre → center, metre → meter |
| -ise | -ize | magnetise → magnetize |
| -isation | -ization | digitisation → digitization |
| -yse | -yze | analyse → analyze |
| -ll- | -l- | modelling → modeling |
| -ogue | -og | dialogue → dialog (`dialog check box`, category 19) |
| ae, oe | e | aluminium → aluminum (`aluminum alloy`, category 4) |

## Notes

- Two failure modes to avoid: a suffix rule that rewrites a proper noun or a
  quoted text (rule 8.6 says you cannot change either), and a rule that rewrites
  a technical noun that a company spells its own way. Both are reasons to check
  against a table plus the dictionary rather than against a regular expression
  alone.
- `-ize` is also the American form of many verbs that are technical verbs
  (magnetize, digitize, normalize), so the table and the glossary must agree.
