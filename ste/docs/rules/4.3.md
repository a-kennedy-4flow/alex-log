# Rule 4.3 — Vertical lists

**Statement** (Issue 9, page 1-4-4)
> Use a vertical list for complex text.

- **Applies to:** a sentence that includes many items or actions, and every
  vertical list that the text already has.
- **Needs:** structure (which lines are list items and what the lead-in sentence
  is).
- **Decidable:** the formatting rules yes. Whether a sentence is "complex enough"
  to need a list is a recommendation.
- **Code:** not implemented.

## Discrete form

```
check(text, structure S) -> [finding]

# a) should this be a list?
for each sentence s of text that is not a list lead-in:
    if s enumerates 4 or more items or 3 or more actions:
        finding(s, :use_a_vertical_list, severity: :recommendation)

# b) is the existing list written correctly?
for each vertical list l of S:
    if the lead-in sentence does not end with ":":        finding(l, :missing_colon)
    if an item does not start with an uppercase letter:   finding(item, :not_capitalized)
    if an item ends with "," or ";":                      finding(item, :bad_item_punctuation)
    if an item is a full sentence and has no period:      finding(item, :missing_period)
    if an item is not a full sentence and has a period
       and it is not the last item:                       finding(item, :unwanted_period)
    if the last item has no period:                       finding(item, :missing_final_period)
    if an item does not connect to the lead-in:           finding(item, :broken_lead_in)
    if the list has a nested list:                        finding(l, :nested_list)
    if the list mixes procedural and descriptive items:   finding(l, :mixed_modes)

pass = findings without severity :recommendation == []
```

## The rules of the list, from the standard

- Put a colon at the end of the lead-in sentence.
- Identify each item with a number, letter, punctuation mark, or symbol (dash,
  bullet, letter, number).
- Start each item with an uppercase letter.
- Where applicable, use an article before the noun that is the subject of the item.
- Put a period at the end of an item that is a full sentence, and at the end of
  the last item; no period on an item that is not a full sentence.
- No comma and no semicolon at the end of an item.
- Do not mix procedural and descriptive writing in one list.
- Keep all items at the same level: no list inside a list.
- In safety instructions, put the negative command in each item: `- DO NOT PUT
  YOUR FEET ON THE APU LINE.`, not `DO NOT:` followed by items.

## Word count

Rule 8.4: the colon of the lead-in has the same effect as a period, so the lead-in
obeys the 20-word or 25-word limit on its own, and each item counts as a new
sentence with its own limit.

## Notes

- The nesting example of the standard is worth keeping as a test: a nested list is
  repaired by putting the sub-items in parentheses on the parent item, not by
  indenting them.
